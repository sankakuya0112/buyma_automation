# BUYMA 競合ショッパーの画像加工実態 (調査ノート)

## 目的

Phase 3-2「画像加工の自動化」着手前に、トップショッパーが商品画像にどんな
加工をしているかを把握し、必要な機能要件を見極める。

## 調査方法

Claude Code サーバから BUYMA に直接アクセスできないため、ユーザに以下の観察を
依頼する。

### 観察対象 (BUYMA で「人気順」「販売実績順」上位)

下記カテゴリで TOP 10 ショッパーをサンプリング:
- ハイブランドバッグ (Gucci, Prada 等)
- ハイブランドシューズ (Christian Louboutin, Jimmy Choo 等)
- ブティック衣料 (Acne, Maison Margiela 等)

### チェック項目 (各ショッパーで)

1. **メイン画像にロゴ/透かしが入っているか**
   - 入っている: ショップ名・LINE ID・URL・「正規品」スタンプ等
   - 入っていない: 仕入先サイトの画像をほぼそのまま使用
2. **背景処理**
   - 白背景に統一している
   - 仕入先サイトのまま (グレー、グラデ等)
3. **追加情報の埋め込み**
   - 「日本未入荷」「即発送」「最安値」等のオーバーレイ文字
   - 価格を画像に焼き込んでいる
4. **写真の追加加工**
   - 商品の細部 (タグ・縫製等) のクローズアップ写真を自前撮影
   - 着用イメージのコラージュ
5. **コーディネート提案**
   - 別商品との合わせ画像

## 一般論 (Claude 知見ベース・要検証)

### 大手プロショッパー (個人月商 100 万超)

- **多くがロゴ/透かしを入れている** (画像盗用対策 + ブランディング)
- 透かしは通常 右下/左下に薄く (透明度 30-50%)
- 「正規品」スタンプを目立つ位置に配置するケースあり

### 中堅ショッパー

- ロゴ無しのまま仕入先画像を使う割合が多い
- BUYMA の規約上「商品の判別ができる画像」であれば加工は必須ではない

### BUYMA の規約上の制約 (公式ヘルプ参照、2026 年時点)

- 仕入先サイトの画像をそのまま使うことは可
- 別ショッパーの画像を盗用すると違反 → 出品取下げ・最悪アカウント停止
- 自分のロゴ・透かしを入れることは可 (むしろ推奨)
- 商品が判別不可能になる加工は禁止 (色を変える等)

## 機能要件案 (実装する場合)

A. **ロゴ透かし合成 (基本)** — Pillow で実装 ~200 行
   - 設定ファイルでロゴ画像パス・位置 (corner)・透明度・サイズ を指定
   - メイン画像 + サブ画像全部に自動適用

B. **背景除去/置換 (上級)** — rembg ライブラリ等で実装 ~500 行
   - ML モデルで商品を切り抜き → 白背景に合成
   - GPU/CPU 重い

C. **オーバーレイ文字追加 (中)** — Pillow で実装 ~100 行
   - 「日本未入荷」「即発送」等のテキストを画像角に配置

## 現時点の判断 (要ユーザ調査後に確定)

- B (背景除去) はオーバースペックの可能性大、優先度低
- A (ロゴ) は競合状況次第。多数の上位ショッパーが入れているなら必須
- C (オーバーレイ) は広告効果の検証後に判断

## ユーザにお願いしたいこと

次セッション開始前に、上記「観察対象」3 カテゴリで上位 5-10 ショッパーを見て:
1. ロゴ入り画像を使っている割合
2. 背景処理しているか
3. オーバーレイテキストの有無

をスクショ 5-10 枚程度で共有してもらえれば、機能要件を確定できる。
