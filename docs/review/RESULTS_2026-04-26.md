### 観察 1: high_competition 6 件は全て「両条件成立」

high_competition で SKIP された 6 件は**全件 median < breakeven** も併発しており、戦略を切り替えても出品しても赤字確定。SKIP 判定として極めて妥当。

### 観察 2: GIVENCHY n=28 は典型例

メジャーブランド (GIVENCHY) は BUYMA 上での流通量が桁違いに多い (n=28)。median ¥115k に対し breakeven ¥174k で**¥59k の赤字**になる。新規アカウントが価格競争に参入しても勝てない好例。

### 観察 3: THE LATEST 2 件の median が怪しい (要検証)

THE LATEST の median ¥26-30k は「BUYMA で『THE LATEST』検索 → デフォルト商品リスト混入」の可能性が高い:

- THE LATEST の cost は ¥27-29k (€146-152)
- median ¥26k は cost を**わずかに**下回る程度
- 偽相場ガード (cost × 50% = ¥13.5k) は超えるので fake_market 扱いにならない
- だが「BUYMA で本当に同等品が ¥26k で売られている」のは考えにくい

**仮説**: THE LATEST は BUYMA で実際に競合 0-1 件 + デフォルト商品 10 件で n=11 に膨らみ、median が低めに落ち着いている可能性。

**検証案**: 
- 偽相場ガードの cost ratio を 0.5 → 0.95 に引き上げ → THE LATEST が `fake_market` 扱いで救済される
- ただし正規の高競合ブランド (TOM FORD/GIVENCHY) は median 実勢価格なので影響しない
- 副作用として、本物の中央値が cost 近傍の商品 (薄利競合) も fake_market に分類されてしまう

### 観察 4: low_competition (n=0~1) ラベル運用の効果

現状 19 件中 17 件が `competition_level=none` だが、`low` (n=1) 該当は 0 件。BUYMA fetch ロジックで「サンプル 0 件」と「サンプル 1 件以上で全部 default 混入」の判別が現状曖昧。次バージョンで fetch 側に「default 商品判別 (price=¥25,980 等の頻出値除外)」を入れると精度が上がる。

## 残課題 (中期対応)

### 1. fetch_buyma_market_prices.py の精度改善

- BUYMA の "該当なしデフォルト商品" の検出ロジック
  - 現在: ブランド検索 → 上位 N 件取得 → 統計
  - 改善: タイトル一致度・SKU 一致度でフィルタ
  - もしくは price=¥25,980 等の頻出デフォルト価格を除外

### 2. 低競合判定の閾値再検討

- 現状 LOW_COMPETITION_THRESHOLD=1 だが、`none` (n=0) と `low` (n=1) の挙動を区別すべきか
- 候補: low の場合、target と median の比較でフラグ立てる（n=1 は信頼できない可能性高い）

### 3. UNRELIABLE_MARKET_COST_RATIO の調整

- 現状 0.5 (median < cost × 50% は偽相場)
- 現実には cost × 80% でも怪しい (薄利競合は実在し得るが新規アカウントで参入しても勝てない)
- 案: 0.5 → 0.7 に引き上げ + 競合密度ラベルとの組み合わせで最終判定

### 4. 実販売データの取得

- 出品 → 成約 → 利益のクローズドループがまだ不完全
- BUYMA 管理画面スクレイプで実販売データを蓄積し、
  「median ¥X で出品した商品の成約率」を観測して閾値調整に使う

## 結論

- **Tier 1 (数値訂正) は問題なく動作**: 全件が利益率 25% 以上で防衛
- **Tier 2 (低競合戦略) は概ね期待通り**: SKIP 9 件のうち 6 件は妥当な高競合除外
- **THE LATEST 系 2 件は偽相場混入の疑い**: 戦略文書の修正と fetch ロジック改善が必要
- **AFTERCOAT が想定通りの低競合コア商品として機能**: 4 件すべて出品可
- **次の論点**: 連続出品テストで BUYMA 側の反応 (閲覧数・お気に入り・成約) を観察し、低競合戦略が「需要ゼロ」でないことを実証する
