## 詳細対応

### 1. 月次純利益の楽観的見積もり

**指摘**: 「20件で83.3万円」は実現利益ではなく「売れたら合計」に近い。

**対応**: 低競合戦略への方針転換で、出品数を「売れる見込みのある数」に
絞る。`docs/strategy/LOW_COMPETITION_STRATEGY.md` で運用ポリシーを明文化。
期待値は評価稼ぎ期で月 1-3 件、中期で月 5-10 件、長期で月 15+ 件。

### 2. 原価計算の数値誤り (即修正)

#### 2a. 為替レート

- **旧**: `DEFAULT_EXCHANGE_RATES["EUR"] = 163.0`
- **新**: `DEFAULT_EXCHANGE_RATES["EUR"] = 186.0` (ECB 2026-04-23 参考値)
- **運用**: 環境変数 `EUR_TO_JPY` で月次上書き可能に
- **影響**: 原価が一律 +14% → target 価格と breakeven も連動して上昇

#### 2b-2d. 手数料体系の修正

- **旧**: BUYMA 5.8% + 決済 3.0% = 8.8% (誤)
- **新**: BUYMA 成約手数料 7.7% + 振込手数料 ¥330/件
- 決済手数料は**購入者負担**のため 0 とする
- 振込手数料は原価に含める (入金時に差し引かれるため)

#### 2e-2g. 中期対応

- VAT 還付率: 実請求書ベースで要検証 (baseblu 購入 1 件で確認)
- 送料 3,000 円/kg: baseblu 公開送料表 (50 EUR / 30 EUR over 850 EUR) を
  反映する方向
- 関税率: カテゴリ別テーブルは既にあり、HS コード単位の精緻化は将来

### 3. 最低利益 floor

**旧**: 全カテゴリ一律 `max(¥5,000, 売価 × 5%)`

**新**: カテゴリ別
- CLOTHING / FOOTWEAR: `max(¥10,000, 売価 × 8%)` (返品リスク高)
- BAGS: `max(¥8,000, 売価 × 6%)`
- ACCESSORIES / 他: `max(¥5,000, 売価 × 5%)`

### 4. 市場ポジションの見直し

**旧**: 中央値 -5% で並べる (強気)

**新**: 競合密度で分岐
- 競合ゼロ/低 (n ≤ 1): target 採用 (独占なら強気で可)
- 中競合 (n = 3-9): target と 相場-5% の**高いほう**を採用
- 高競合 (n ≥ 10): 出品 SKIP (価格競争で負ける想定)

詳細は `docs/strategy/LOW_COMPETITION_STRATEGY.md`

### 5. 規約・税務リスク

- **直送禁止**: 自社発送のため問題なし (CLAUDE.md に明記)
- **画像権利**: baseblu 規約の調査を Phase 3-2 に積む
- **消費税**: 年商 1000 万円超えで課税事業者化。`sales_report.py` に
  「年商推計 → 課税警告」機能を中期追加予定

### 6. スケール時のボトルネック

月 100 件超えで物理発送と CS が限界。本戦略は**月 15-30 件出品・月 5-15 件成約**
を想定しており、スケール重視ではない。将来的な外注/倉庫化は Phase 3 以降。

### 7. 参入障壁と差別化

**差別化の軸** (LOW_COMPETITION_STRATEGY.md 参照):
- BUYMA に他店出品のない商品を **先行独占**
- 丁寧な商品説明、素材タグの正確性 (Phase B 完了済)
- 「日本未入荷」タグの活用
- 画像権利確認済の自前撮影 (Phase 3-2 実装判断中)
